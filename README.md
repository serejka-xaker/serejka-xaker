### Ключевые проекты

#### [Telegram SaaS Platform](https://github.com/serejka-xaker/Telegram-Saas-Platform)
> SaaS-платформа для централизованного управления парком изолированных Telegram-ботов (Multi-tenancy).
- **Архитектура:** Мастер-бот оркестрирует запуск дочерних ботов в изолированных процессах с индивидуальными конфигурациями и БД.
- **Безопасность:** Разделение данных клиентов, уникальные API-ключи, ролевая модель доступа (RBAC).
- **Стек:** `Python` `aiogram 3` `PostgreSQL` `Docker` `SQLAlchemy Async` `REST API`

#### [Telegram Chat Rating & Moderation Bot](https://github.com/serejka-xaker/Telegram-Chat-Rating-Bot)
> Комплексное решение для модерации чатов и геймификации вовлечённости пользователей.
- **Функционал:** Система рейтинга, автоматическая фильтрация сообщений по стоп-словам, ежедневные сводки, управление через inline-интерфейс.
- **Технологии:** Асинхронная обработка событий, планировщик задач APScheduler, работа с SQLite через aiosqlite.
- **Стек:** `Python` `aiogram` `aiosqlite` `APScheduler` `Babel`

#### [Telegram Multi-Account Commenting Manager](https://github.com/serejka-xaker/Telegram-MultiAccount-Commenting-Manager)
> Инструмент автоматизации массового комментирования с поддержкой ротации аккаунтов и прокси.
- **Возможности:** Импорт сессий, распределение нагрузки, гибкая настройка задержек, мониторинг статистики.
- **Интерфейс:** Управление через CLI или REST API (Flask) с эндпоинтами для статистики, бэкапов и контроля аккаунтов.
- **Стек:** `Python` `Telethon` `Flask` `SQLite` `SOCKS5/HTTP Proxies`

#### [SuperJob Parser with Flask UI](https://github.com/serejka-xaker/SuperJob-Parser-Flask-UI)
> Веб-приложение для парсинга вакансий с интеграцией официального API SuperJob.
- **Особенности:** OAuth 2.0 аутентификация, гибкая фильтрация по профессиям и ключевым словам, экспорт структурированных данных в Excel.
- **Интерфейс:** Интуитивная веб-форма для настройки параметров поиска и запуска задач.
- **Стек:** `Python` `Flask` `Requests` `Pandas` `OpenPyXL` `OAuth 2.0`

#### [Telegram Channels Parser](https://github.com/serejka-xaker/Telegram-Channels-Parser)
> Асинхронный парсер для сбора и анализа контента из множества Telegram-каналов.
- **Функционал:** Сбор сообщений за указанный период, фильтрация по ключевым словам, сохранение метаданных и ссылок в Excel.
- **Производительность:** Асинхронные запросы через Telethon для эффективной обработки больших объёмов данных.
- **Стек:** `Python` `Telethon` `AsyncIO` `Pandas` `OpenPyXL`
